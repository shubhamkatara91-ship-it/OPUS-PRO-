# OPUS PRO Android build

This directory contains the native Android WebView shell (version 1.4.7). The app defaults to the configured OPUS PRO HTTPS backend and allows changing the server from the app menu. GitHub Actions builds a debug APK with `gradle assembleDebug` and uploads it as an Actions artifact. The APK requires an HTTPS OPUS PRO backend URL on first launch; no production backend is bundled in this shell. The WebView loads the independent OPUS dashboard and its live-provider status, 30-second/1-minute cycle selector, eight lookback tools, and provider history endpoints. Live records are shown only after a verified read-only provider is configured; the 500-row raw-history archive does not guess BIG/SMALL from unverified numeric rules.
